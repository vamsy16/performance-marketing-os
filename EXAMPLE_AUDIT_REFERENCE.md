# Example full audit — reference for agents

This is the **gold-standard example** of a correctly built full audit in this repo.
Give the PDF to an agent as a visual reference, but require it to **re-run the
pipeline for its own lead**. Never copy or reuse this PDF for outreach.

For the full copy-paste run sheet, give the agent `AGENT_HANDOFF.md` alongside
this file, `MANDATORY_AUDIT_CHECKS.md`, and the PDF.

## What this example proves

- 7-page **full audit**, not an ads-only report and not an internal draft.
- Website score: **12/100** (numeric, from live page checks — lower is better).
- **4 live Meta ads** attributed to the exact page `SunSolarhyd`, each with a
  direct `facebook.com/ads/library/?id=<ID>` permalink and verbatim copy.
- PageSpeed is reported honestly as **"Not available at audit time (API returned 429)"** — no invented speed score or LCP.
- Google Ads Transparency was queried; no own advertiser record was found. Competitor counts come from the live sweeps.
- The featured three ad cards are genuinely the three most recent by captured start date.
- The page-6 verification table describes only what was actually measured.
- Every mandatory website check in `MANDATORY_AUDIT_CHECKS.md` is resolved to a
  real observed value — no `None`, "Not found" or "Not checked in this pass"
  for tracking tags, conversion elements, SEO, images, sitemap, local signals,
  SSL or server response time.
- No `INTERNAL DRAFT`, `NOT SCORED`, `SOURCE DATE NOT VERIFIED`, or one-sample-ad placeholders.

## Reproduce it (on the owner's Windows machine, with Chrome + live internet)

From the repo root:

```powershell
cd 01-LEADS
python run_pipeline.py https://www.sunsolar.info/ "SunSolar Power Systems" --city Hyderabad
```

`run_pipeline.py` does all three steps: live website audit, live Meta/Google ad
research, then the branded PDF. It also runs the delivery gate itself and will
refuse to print `DONE` unless the report is complete, fresh, and pipeline-built.

## Mandatory gates, in order

Run from `01-LEADS/`. Every command must exit `0`.

```powershell
python verify_report.py "SunSolar Power Systems"
python delivery_gate.py "SunSolar Power Systems"
python verify_live.py --company "SunSolar Power Systems" --timeout 25 --retries 2
```

Then the two agents must report:

- `REPORT REVIEW: PASS` (`report-reviewer`)
- `LIVE-DATA CHECK: PASS` (`live-data-auditor`)

`verify_live.py --offline` exits `4` and is **not** a live pass. A bare
`requests` GET to Facebook returns a 403 challenge; use Chrome. If live sources
cannot be reached, **stop and say so** — do not build a hand-made "internal
draft" that looks like a client report.

## Rules for any agent using this reference

1. Read `AGENTS.md` at the repo root first. It is the contract. Also read
   `MANDATORY_AUDIT_CHECKS.md`; an audit with an unresolved mandatory website
   check is **not complete** and must not be reported as done or delivered.
   `audit_completeness.unresolved()` must return `[]` for the report.
2. Never invent, estimate, or paraphrase an audit number or ad count.
3. Ad copy is reproduced verbatim. ₹ renders as `Rs. ` under base-14 fonts;
   Indic-script copy uses an explicit placeholder, never a guess.
4. Attribute ads by direct Library ID fetch. Search-engine caches and
   one-card fallbacks have caused real misattributions here.
5. A destination is "confirmed" only if the live ad card states one. Otherwise
   the report must say "Not confirmed from the ad card in this pass", and no
   email may claim more.
6. PageSpeed blocked by HTTP 429 stays unavailable. Never fabricate a score.
7. Every PDF must be generated by `run_pipeline.py` / `ads_only_report.py`.
   Hand-rolled PDFs, monkeypatched renderers, and one-ad drafts are holds and
   fail `delivery_gate.py`.
8. All audits follow the Ksquare 5-page layout plus the claude-ads control
   review — see `AUDIT_FORMAT_STANDARD.md`.
9. Legacy reports in `ads_only_pdfs/` and `audit_pdfs/` that are stamped
   `INTERNAL DRAFT` or have tiny/broken renders are known holds. Do not use
   them as examples and do not weaken a gate to make them pass.
10. Do not send, schedule, or un-trash anything. The owner sends every draft.
