# Arena Prompt Library — Your Free Content Engine

Paste these prompts into Arena Agent Mode to generate all your agency content.
**Save every output** to your client folders.

## How to use Arena for your agency
1. Open Arena.ai → Agent Mode
2. Pick a model (Claude or GPT-class models work best for writing)
3. Paste prompt + fill in [BRACKETS]
4. Save output to Google Drive folder
5. Tweak and deliver

⚠️ **Never paste client confidential info, passwords, or personal data into Arena** — it's a public platform.

## 1. BLOG POSTS (SEO content for clients)

### Prompt: Solar blog post
```
Write a 1,200-word SEO blog post for a solar company in [CITY], India.

Target keyword: "[KEYWORD, e.g., solar panel price in Mumbai 2026]"
Secondary keywords: [2-3 related terms]

Requirements:
- H2 and H3 subheadings
- Include current Indian solar subsidy info (PM Surya Ghar scheme)
- Compare costs with and without subsidy
- Include a cost table in INR
- FAQ section at the end (5 questions)
- Natural, helpful tone — not salesy
- End with a soft CTA to contact the company

Company: [COMPANY NAME]
Service area: [CITY + SURROUNDING AREAS]
```

### Prompt: Solar cost calculator post
```
Write a blog post titled "How Much Do Solar Panels Cost in [CITY] in 2026?"

Structure:
1. Current average costs (1kW, 3kW, 5kW, 10kW systems) in ₹
2. PM Surya Ghar subsidy amounts
3. Payback period calculation
4. Monthly savings vs. electricity bill
5. Factors that affect price (roof type, shade, panel brand)
6. CTA to get a free quote

Make it genuinely useful — the reader should be able to budget after reading.
Keep it under 1,500 words. Use tables for numbers.
```

## 2. SOCIAL MEDIA CONTENT

```
Create content for a 10-slide Instagram carousel for a solar company in [CITY].

Topic: [TOPIC, e.g., "5 myths about solar panels in India"]

For each slide:
- Slide number
- Headline text (max 8 words)
- Body text (max 25 words)
- Design notes (what visual/icon to use)

Slide 1: Hook (stop the scroll)
Slides 2-9: Value content
Slide 10: CTA (save/share/follow)

End with 5 relevant hashtags and a caption for the post.
```

```
Platforms: Instagram, Facebook

Make the topics specific to [CITY] climate, electricity rates, and culture.
```
